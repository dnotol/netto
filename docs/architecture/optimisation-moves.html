How the Optimisation tab finds its moves

The moves are what Netto would change in a plan to put more in the director's pocket. They are measured from one plan, searched once per plan and date after the page has painted, found greedily by the engine, and applied only by « Apply ». This page follows one search and one Apply.

As of feature/backlog-bugs 34698cc30 October 2026

One search, then Apply

The baseline (MovesBaseline) is the plan starred « Today » when it is readable, else the river as it stood when the page opened, when a plan was opened, or when it was saved. An edit never changes it. MovesSource, built once by the plan page, keeps the last result per baseline and date, so a search runs again only when the baseline or the day changes.
